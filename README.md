# Smart Recommendation System

A dual-purpose recommendation system suggesting movies 🎬 or books 📚 based on user preferences. Built with Python, scikit-learn, and Streamlit.

## Features
- Movies & Books recommendation
- Content-based filtering using cosine similarity
- Interactive Streamlit interface

## Tech Stack
- Python
- pandas, numpy, scikit-learn
- Streamlit for UI

## How to Run
1. Clone repo
2. Install dependencies: pip install -r requirements.txt
3. Run Streamlit: streamlit run app.py
